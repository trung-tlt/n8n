# n8n Automation Workflows Collection 🚀

A curated collection of **production-ready n8n automation workflows** designed for **AI, DevOps, Cloud, Business Ops, and Integrations**.

This repository serves as a **single source of truth** for all my published and maintained n8n workflows, including templates shared on the n8n marketplace and workflows used in real client projects.

> 🔢 **Total workflows:** 33 (and growing)  
> 🧠 Focus: AI, automation, developer productivity, and system integrations

---

## ✨ What You’ll Find Here

- ✅ Reusable **n8n workflow JSON files**
- 🤖 **AI-powered automations** (LLMs, agents, summarization, enrichment)
- 🔁 Event-driven workflows (webhooks, schedulers, triggers)
- 🔌 Third-party integrations (Cloud, SaaS, APIs)
- 🛠️ Developer & DevOps utilities
- 📦 Ready-to-import workflows for self-hosted n8n
